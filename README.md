# Caller-Portrait-Importer
A custom plugin that allows you to input whatever image you want as a portrait for ScamWYF.

I tested this mod very lightly, so I don't know if it's gonna work with everything, but I guess any issues, just put them here and I'll try and fix them. [Needs this launcher](https://github.com/swyf-modding/Launcher) to work cause it installs everything you need. Then just put it in the plugins folder in BepInEx, Or via the launcher. 
It's pretty easy to follow. Just press the browse button (then a new app will open) and then just pick whatever image you want, and then it continues on to the personalities tab.
